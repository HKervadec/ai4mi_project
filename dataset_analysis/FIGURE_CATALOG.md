# Figure catalog

Every figure produced by the dataset-analysis tooling, what it shows, and
where the idea for it came from. Update this when a figure is added, removed,
or its underlying script changes meaningfully.

Sources referenced below:
- **EDA doc** — the thoracic-CT EDA/QA writeup (coordinate audits, HU ridge
  plots, 3D centroid scatter, spatial occupancy, etc.)
- **planner source** — nnU-Net's own experiment-planning code
  (`determine_fullres_target_spacing`, `crop_to_nonzero`,
  `verify_dataset_integrity`, `CTNormalization`)
- **team** — designed directly for this project, not adapted from an
  external source

## `figures/` (nnU-Net planner + spatial checks, `tools/nnunet_planner_checks.py`)

| Figure | Shows | Source |
|---|---|---|
| `anisotropy.png` | Per-axis spacing distribution + coarseness ratio vs. resampling threshold | planner source (`determine_fullres_target_spacing`) |
| `crop_to_nonzero.png` | Per-patient fraction of volume kept after cropping empty space | planner source (`crop_to_nonzero`) |
| `connected_components.png` | Patients x classes heatmap, component count under 6/18/26-connectivity | planner source (postprocessing rule) + EDA doc (topological integrity audit) |
| `organ_adjacency.png` | Fraction of patients where organ A's mask touches organ B's, all pairs | team (generalizes a manual adjacency check) |
| `ct_normalization.png` | HU histogram, all voxels vs. labeled-organs-only, with clip/mean/std | planner source (`CTNormalization`) |
| `shape_and_fov.png` | Per-axis voxel-count distribution + derived physical field-of-view (mm) | EDA doc (grid dimensions + non-zero tissue extent) |
| `organ_centroids_3d.png` | 3D scatter of organ centroids, one point per organ per patient | EDA doc ("3D Centroid Scatter Matrix") |
| `hu_ridge_by_organ.png` | Overlapping HU density curves per organ | EDA doc ("Class-Conditional HU Ridge Plot") |
| `organ_min_distance.png` | Median minimum surface-to-surface distance (mm), every organ pair | EDA doc (pairwise minimum surface distance) |
| `contrast_spikes.png` | Per-patient brightest voxel (HU), flagged against a metal/contrast threshold | EDA doc (contrast-media / high-density artifact detection) |
| `contour_roughness.png` | Per-organ distribution of slice-to-slice contour jaggedness | EDA doc (slice-to-slice perimeter variance / contour roughness) |
| `occupancy_envelope_3d.png` | 3D isosurface (marching cubes, 50% patient agreement) of each organ's spatial envelope, all 20 patients aligned on their own heart centroid | EDA doc ("Spatial Occupancy Heatmap"), rendered as 3D instead of the doc's 2D MIP |

Structural pass/fail checks (image/label shape, spacing, affine match;
unexpected/missing label values, coordinate-orientation consistency,
any contrast/artifact spike) are **not** rendered as figures — they're
zero-variance by construction (either everything passes or something is
actively broken) and are reported as plain text in `nnunet_checks.md`
instead, the same way `dataset_analysis/validate_results.py` reports its
checks. Source: planner source (`verify_dataset_integrity.py`) + EDA doc
(coordinate orientation audit). Array NaN/Inf integrity was considered and
deliberately skipped — not useful enough to be worth adding.
